# 🏋️ Железный Дневник 2.0 (Iron Diary PWA)

Автономное PWA-приложение для профессиональных тренировок по соревновательному пауэрлифтингу и стронгмену.

## 🚀 Возможности
- **4-дневная программа:**
  - Пн: Тяжёлая соревновательная становая тяга + Жим с паузой + Тяга Крока (хват) + Армейский жим
  - Вт: Соревновательный присед + Присед с паузой 2 сек + Жим узким хватом + Присед/удержание Зерхера
  - Чт: Тяга с паузой под коленом 2 сек + Объёмный жим + Тяга штанги в наклоне + Швунг жимовой
  - Сб: Тяга с плинтов 5–7 см + Наклонный жим + Прогулка фермера + Подтягивания
- **Автоматическая пирамида подводящих подходов** (пустой гриф → 50% → 65% → 80% → 90% → Топ-сет).
- **Калькулятор олимпийских дисков:** визуализация грифа с цветными соревновательными блинами (25, 20, 15, 10, 5, 2.5, 1.25 кг).
- **Авто-таймер отдыха (3–5 мин):** запускается автоматически при выполнении подхода с синтезированным звуковым сигналом и виброоткликом (Haptic API).
- **Умная авторегуляция:** RIR (повторения в запасе) + оценка субъективных ощущений (*Летит / Норма / Давит*).
- **Протокол динамической мобилизации и декомпрессии позвоночника** (чек-листы перед и после тренировки).
- **Оценка готовности ЦНС:** сон, утренний пульс, забитость мышц (DOMS) с авто-коррекцией нагрузки.
- **Массонаборный трекер без калорий:** 6 приёмов пищи, 4 литра воды, чеклист фармакологии и БАД.
- **100% автономность и офлайн режим (PWA):** сохранение в `localStorage`, экспорт всей истории в JSON файл в 1 клик.

## 📱 Установка на телефон (iOS / Android)
1. Открой ссылку в Safari (на iPhone) или Chrome (на Android).
2. Нажми кнопку **«Поделиться»** (иконка со стрелочкой вверх на iOS или три точки в Chrome).
3. Выбери **«На экран Домой»** («Добавить на главный экран»).
4. На телефоне появится приложение «ЖД 2.0», которое работает на весь экран без рамок браузера даже без интернета!
