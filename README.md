# ЖЕЛЕЗНЫЙ ДНЕВНИК · IRON DIARY PWA

Автономная мобильная лаборатория силового троеборья и стронгмена. Приложение спроектировано для работы со смартфона в тренажёрном зале в 100% офлайн-режиме (GitHub Pages + Service Worker + `localStorage`).

Дизайн-система: **Apple Liquid Glass & Obsidian Chrome** — глубокий оникс (`#060709`) под OLED-дисплеи, матовое рифлёное стекло с `backdrop-filter`, контрастная типографика (`Unbounded`, `JetBrains Mono`, `Manrope`), зоны нажатия от 44px для работы руками в магнезии, полное отсутствие эмодзи и визуального шума.

## 1. Биомеханический и методический расчёт под профиль атлета

- **Антропометрия**: рост 190 см, вес 95 кг (целевая категория 125+ кг), размах рук 203 см.
- **Коэффициент рычагов (Ape Index)**: `203 / 190 = 1,068` (+13 см к росту).
- **Лучшие соревновательные результаты**: присед 190 кг, жим лёжа 140 кг, становая тяга 230 кг (сумо) / 200 кг (классика), сумма 560 кг @ 95 кг.

### Почему классика биомеханически оптимальна при размахе 203 см
1. **Высота замка**: длинные руки (+13 см к росту) опускают хват на 6–7 см ниже среднестатистического атлета роста 190 см. Это позволяет стартовать с более высоким положением таза и открытым углом в коленном суставе, сокращая путь штанги.
2. **Причина дискомфорта в сумо**: длинная бедренная кость требует предельно широкой постановки стоп и экстремальной наружной ротации бедра, чтобы вывести таз близко к грифу. Это перегружает приводящие мышцы и связочный аппарат таза.
3. **Стратегия перехода и частой тяги (3 раза в неделю без перегрузки ЦНС)**:
   - **Понедельник (Тяжёлая соревновательная классика)**: выход на 1 топ-сет дня + сброс 10–12% в рабочих подходах (Back-off). База расчёта в Цикле 1 — 200 кг.
   - **Четверг (Перегрузочная тяга с плинтов ниже колена, `k = 1.05`)**: работа с весами выше соревновательного классического максимума в укороченной амплитуде. Приучает верх спины, хват и разгибатели к сверхтяжёлым весам без избыточной нагрузки на связки таза и ЦНС.
   - **Суббота (Техническая вариация без топ-сета, 72–84%)**: в первой волне (недели 1–3) — **тяга из ямы 4–5 см** (`k = 0.88`) для развития срыва ногами; во второй волне (недели 4–6) — **тяга с паузой 2 с ниже колена** (`k = 0.85`) для жёсткого удержания позиции спины при обходе длинных бёдер.

## 2. Недельный 4-дневный сплит и волновая периодизация

### Структура микроцикла
| День | Фокус сессии | Упражнения |
|---|---|---|
| **ПН · День 1** | Тяга · Жим | Становая тяга классическая (Топ-сет + Back-off), Жим лёжа с паузой (Топ-сет + Back-off), Тяга штанги в наклоне, Тяга Крока 2×15–20 (хват), Прогулка фермера 4×30 м, Ролик для пресса |
| **ВТ · День 2** | Присед · Плечи | Присед со штангой (Топ-сет + Back-off), Армейский жим стоя (Топ-сет + Back-off), Тяга Т-грифа, Удержание Зерхера из рамы 3×20–30 с, Подъём ног в висе |
| **ЧТ · День 3** | Плинты · Объём | Тяга с плинтов (Топ-сет + Back-off), Жим лёжа объёмный (5×5 / 5×4 / 4×3), Швунг жимовой (5×3 / 5×2), Подтягивания с весом, Прогулка с чемоданом 3×30 м |
| **СБ · День 4** | Пауза · Яма/Колено | Присед с паузой 2 с (Топ-сет + Back-off), Тяга из ямы / Тяга с паузой у колена, Жим узким хватом, Тяга Пендлея, Гиперэкстензия с весом, Удержание блинов щипком |

### 8-недельный волновой макроцикл
- **Волна 1**: Неделя 1 — Накопление (Топ-сет 5 @ 77,5%, RIR 2, Back-off −12% 4×5) → Неделя 2 — Развитие (Топ-сет 4 @ 82,5%, RIR 2, Back-off 4×4) → Неделя 3 — Интенсификация (Топ-сет 3 @ 87,5%, RIR 1, Back-off −10% 3×3).
- **Волна 2**: Неделя 4 — Накопление II (Топ-сет 5 @ 80%, RIR 2, Back-off 4×5) → Неделя 5 — Интенсификация II (Топ-сет 3 @ 88,5%, RIR 1, Back-off 3×3) → Неделя 6 — Реализация (Топ-сет 2 @ 92,5%, RIR 1, Back-off 3×2).
- **Финиш**: Неделя 7 — Разгрузка (3×3 @ 65%, RIR 3, без топ-сетов и плинтов) → Неделя 8 — Контрольный тест (Топ-сет 1 @ 97,5% @ RIR 1 + пересчёт максимумов на следующий цикл по e1RM).

## 4. Развёртывание на GitHub Pages и установка на смартфон

1. Загрузите содержимое папки `iron-diary` в корень репозитория GitHub (ветка `main`).
2. В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите источник **Deploy from a branch (`main` / `/ (root)`)**.
3. Откройте опубликованную ссылку на смартфоне:
   - **iOS (Safari)**: нажмите кнопку **«Поделиться»** → **«На экран Домой»**.
   - **Android (Chrome)**: нажмите меню браузера (три точки) → **«Установить приложение»**.
